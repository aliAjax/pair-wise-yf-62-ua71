# 海上搜救联合指挥

源提示词摘要：按海域划设搜索区，协调船艇、直升机、无人机和岸上观察点，记录任务变更、通信与天气影响；离线单位恢复后合并状态，过期位置必须明确提示，并提供低带宽模式。

## 技术栈

Next.js 15、TypeScript、App Router、Mantine、Zustand、TanStack Query、React Hook Form、Zod、next-intl、date-fns、MapLibre。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62027`

## 可用流程

- 搜索区从规划、执行到关闭，支持任务范围变更。
- 船艇、直升机、无人机、岸上观察点可调派、转入失联、恢复在线。
- 任务单支持新建议题、分配单位、关闭任务和事件留痕。
- 离线模拟与低带宽模式可切换；本地数据由 Zustand persist 保存。

## 失联归队合并规则

失联单位在本地积累位置与覆盖记录，网络恢复后一键“合并归队”，接入指挥台态势：

- **只认观测时间**：位置是否过期（默认 10 分钟）一律按记录自带的观测时间判定；过期只挂起提示“需重算”，绝不把恢复时刻坐标当新位置。更旧的观测不会回退在位数据。
- **任务记录优先**：单位已被调给新任务时，回报的旧搜索区不覆盖任务安排，覆盖按现行任务改投到实际执行区，并保留“原回报区”来源标记。
- **冲突不自动选值**：不同单位对同一区覆盖率矛盾（差 >5 个百分点），或同一单位同时分到两个区，只列入“冲突定夺”由指挥员裁定；未定夺前相关覆盖整批挂起，原覆盖值保留。
- **来源可追溯**：每个搜索区列出每笔覆盖的单位、数值、观测时间与改投标记；每次合并生成结构化摘要（位置更新/过期、覆盖并入、改投、新冲突计数），低带宽模式下保留摘要、在岗情况与定夺入口，关闭地图与明细。
